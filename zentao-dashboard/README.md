# 禅道质量看板

DSH 原生插件，安装后从左侧「禅道质量看板」进入。无需独立服务器、Docker 或前端构建。

- 默认全局首页：自动遍历全部可见项目，只列未关闭冲刺（status != closed），包括已关闭项目下遗留冲刺，无需选择项目、产品或切换冲刺。
- 跨项目冲刺表：所有未关闭冲刺同时展示计划截止、需求关闭率、任务完成率、待解决/待验证缺陷及延期风险，不展示负责人列。
- 每行支持“忽略”；“已忽略”展开名称清单，可取消忽略。本机清单保存于插件目录 .local/ignored-sprints.json，受 Git 忽略保护，刷新与重启后保留。忽略只影响上方关注冲刺及其统计，不加载该冲刺的需求和任务；其缺陷仍读取，用于底部独立的线上问题汇总。轻量目录仍读取以发现新冲刺。
- 最近30天线上问题：独立覆盖全部未关闭冲刺（含已忽略项），保留最近30个自然日创建且 onlineIssue=1 的缺陷，含今天、上海时区；包含待解决、待验证、已关闭，按 Bug ID 去重，并显示状态数量与时间范围。不受忽略清单影响。
- 紧凑样式：页面边距12px、正文13px、表格单元格上下6px、卡片内边距10px。
- 缺陷跟进：未关闭、待验证、P1/P2 未关闭、超过7天未解决，创建人/状态/关键词筛选、分页及原单跳转。创建人使用 openedBy 关联禅道用户 realname，不使用当前指派人；姓名无法获取时明确显示“姓名未获取”，不冒充真实姓名。
- 需求按 closed / 全部计算；任务排除取消与父任务，done、closed 计入完成。关闭需求可能包含非交付关闭，请结合原单核实。
- 底部不再展示标题候选或普通测试缺陷，仅展示原生线上标记。顶部汇总指标仍为全部未关闭冲刺的整体范围。
- 问题龄期为创建时间至今（上海时区）的自然日，不代表 SLA 或实际处理中耗时。
- 全量分页只限当前账号权限范围。任何分项读取失败显示未评估，保留其他成功项。

## 本机依赖与认证

使用 Python3 运行已配置的 zentao-qa 脚本，通过其禅道 v1 接口读取数据及自动续期。插件不包含密码或 Token，不向浏览器返回凭据。当前机器已通过 doctor 验证账号与站点，可复用已有配置，无需重新保存用户密码。

默认脚本为 /Users/linjt/.agents/skills/zentao-qa/scripts/zentao_qa.py。其他机器可通过 ZENTAO_QA_SCRIPT 指定脚本，ZENTAO_QA_CONFIG 指定该工具的本地配置。按照 zentao-qa 登录流程配置认证；本机配置应放在被忽略的 .local 目录，权限0600。

只读 GET 查询使用60秒内存缓存；刷新全局会重新加载全局汇总，60秒内可能复用缓存。全局采集最多4个在途请求，共享进行中的采集，避免重复请求。每次脚本调用最多120秒；错误不返回脚本输出，避免泄漏敏感信息。不提供禅道写入动作。

## 安装

通过当前 DSH 的 plugin_manager install_bundle，target 指向此目录的绝对路径。本地目录安装由 DSH 管理；升级已加载版本可能需要重启 DSH，以安装结果为准。

## 验证

运行 node --check client.js、node --check index.js、node --test global.test.js；验证未关闭过滤、跨项目缺陷去重、分项失败和父子任务口径，并读取真实全局汇总。不启动浏览器，因此视觉布局与点击验收需用户在现有 DSH 页面确认。
