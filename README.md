# Harness 插件集合

用于开发和维护 DeepSeek Harness 插件。每个插件拥有独立目录、依赖、构建与使用说明。

## 插件目录

| 插件 | 目录 | 功能 |
| --- | --- | --- |
| ACP 会员额度仪表盘 | [acp-quota-dashboard](acp-quota-dashboard/) | 在模型旁显示 Google AI Pro 额度、重置时间和所属账号；保留 ACP Agent 适配能力 |
| 个人工作台 | [dsh-workbench](dsh-workbench/) | 在左侧主菜单提供工作台入口，支持多通道会话采集、事项待办、日报、周报与月报自动生成 |

## 开发约定

- 后续插件按 `插件目录/` 独立组织，在各自目录中安装依赖、开发和打包。
- 不提交 `node_modules`、构建产物、账号凭据、运行日志或个人环境配置。
- 上游派生插件保留来源说明与原有许可。每个插件的兼容性和验证范围以目录内 README 为准。
