# 侧栏紧凑布局

独立的 Harness 客户端插件。保留「插件」「自动化任务」「更多」为整行，自定义插件入口自动排列成双列；继续使用原来的图标、选中状态、键盘操作和点击行为。

- 不额外添加侧栏入口，不改动其他插件，不修改宿主文件。
- 监听菜单变化和语言切换，后续新增的自定义入口自动适配。
- 长名称省略显示，悬停显示完整名称；宿主已有提示时优先保留。
- 侧栏折叠时恢复原布局；停用或卸载时清理样式、标记及补充的提示。
- 系统入口按 `plugins`、`schedules` 标识识别，「更多」按菜单按钮识别；无法识别或同名的入口保留整行。

## 安装

在 Harness 的插件管理中使用本地目录安装功能，选择本目录：

```text
/Users/linjt/Documents/projects/harness-plugin/sidebar-compact-layout
```

支持安装 ZIP 包的版本也可以使用 `sidebar-compact-layout.zip`。无需安装依赖或构建。启用后生效，停用后恢复；是否需要重载客户端以插件管理器提示为准。

## 兼容性

根据本机 DSH NEXT 中的 `@deepseek-ai/dsh-client-ui-sidebar@0.2.2-rc.1` 实现适配。通过 `sidebar.panellist` 读取菜单，再从宿主样式表识别菜单容器；双列属于样式适配，并非 Harness 的正式布局 API。宿主结构变化可能需要更新本插件，无法识别宿主样式时不改变布局。

只影响侧栏菜单，不影响工作区、会话列表及底部额度区域。没有移动按钮、替换组件或接管点击事件。

## 验证

```sh
cd sidebar-compact-layout
npm run check
npm test
```

自动验证覆盖菜单分类、折叠恢复、动态入口与语言变化、停用清理。未启动浏览器；真实宿主中的视觉、点击和启停效果仍需安装后确认。
