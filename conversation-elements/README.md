# 冰火对话

在 Harness 的插件管理中导入本目录或插件 ZIP 并启用，无需构建。

- 当前对话运行时，发送消息输入框上沿燃起高低错落的火簇，较高处有零星余烬上浮、渐隐。正文仍可选中、滚动和操作。
- 当前对话可见且任务空闲时，鼠标移动、输入、触摸或滚动均重新计时。连续 60 秒无操作，冰层覆盖整个窗口。
- 冻结后光标变为锤子。单击冰面，裂纹从落点扩散，大小不同的冰片随之翻转落下。也可以按 Enter、空格或 Esc 恢复。系统启用减少动态效果时直接解冻。
- 运行新任务、离开对话或停用插件会清理特效。切换到后台暂停计时，返回后重新开始。

使用宿主的 conversation.composer.dock 插槽与当前会话的 running 状态。效果适用于已挂载该插槽的会话；新会话欢迎页尚未挂载时不计时。

在本目录执行 `npm run check` 和 `npm test` 可验证语法和模拟宿主中的状态切换。
