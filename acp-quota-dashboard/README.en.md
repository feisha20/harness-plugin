# ACP Quota Dashboard

[中文](README.md)

ACP adapter with Codex and Antigravity quota panels and cancellable follow-up for long Antigravity commands. Connect ACP Agents such as Antigravity, Codex, Devin, and Claude in the plugin settings.

The private package `@feisha20/dsh-acp-adapter` targets `@deepseek-ai/dsh` `0.2.2-rc.5` (DSH NEXT `2.0.24-next`). Build and pack it from this repository, then install the local tarball. See the [build and migration instructions](README.md).

The source is based on upstream [ACP adapter v0.2.2-rc.5.1](https://github.com/zaimokuza-yoshiteru/dsh-acp-adapter/releases/tag/v0.2.2-rc.5.1) and retains its [MIT license](LICENSE).
