# ACP 额度仪表插件开发约定

- 更新说明、提交说明、产品文案和新增注释使用中文。
- macOS 上使用 Python3。除非用户要求，不启动浏览器测试；不擅自构建 Docker 镜像。
- 修改范围限于本插件目录；优先使用 Harness 公开插槽和官方 Antigravity CLI 状态行。
- 不读取 OAuth 凭据，不调用私有额度接口，不自动轮换账号。账号与额度只来自官方 CLI 同批次结果。
- 保留 MIT 许可与上游来源；上游约定保存在 docs/上游开发约定.md，本地功能说明见 docs/会员额度二次开发.md。
- 依赖、构建产物、运行证据与配置不得提交；维护 .gitignore。包保留上游内部标识，private 防止误发布同名 npm 包。
- 按变更运行必要构建、类型检查与测试；安装和真实账号验证需基于用户授权，不能把历史验证当作当前通过。
- 验证使用隔离 profile；不要覆盖正在运行的插件产物，不删除用户会话或认证数据。
