# 活动记录性能优化（quota.4.5）

新增活动详情超过 1 KiB 且压缩后至少节省 10% 时，使用低级别 DEFLATE 无损压缩，存入新增 BLOB 列。读取时兼容旧文本，解压输出限制为 4 MiB。压缩失败或损坏数据不会伪装成正常历史。小详情保留文本，重复状态在压缩前去重。

同一活动的状态、展示文案、原始详情、详情引用和结构化展示均相同时，不因时间戳变化新增修订；保留上一次状态的时间及修订号。不可变身份和终态校验仍先执行。不会删除已有重复历史，也不会合并不同的真实状态变化。

活动流先订阅，再固定会话修订上界；分页只取各活动在上界内的最新状态，旧数据源仍使用历史回放。后续修订从订阅队列交付，旧历史仍支持按修订号查询。不会将有限条快照误当成整个会话。

## 历史库压缩

正常启动只添加可空列，不扫描重写历史。以下命令使用 SQLite backup API 获取一致副本，仅修改副本，拒绝覆盖目标文件：

```bash
python3 scripts/compact-activity-copy.py --source "$HOME/.dsh/dsh-acp/sidecar.sqlite" --output /绝对路径/sidecar-compact.sqlite
```

工具保留全部修订及其他表；压缩前后计算完整活动内容摘要，执行数据库完整性检查，最后 VACUUM 副本。源库可以运行，但副本只代表备份时刻；有新增对话后不能用旧副本覆盖源库。

安装及应用压缩副本前必须退出 Harness，并备份插件、配置与数据库（包括存在的 WAL）。退出后重新生成压缩副本，再替换数据库。运行中不得直接替换库或删除 WAL。新版本支持混合读取新旧存储；旧插件无法读取压缩字段，降级须同时恢复升级前的数据库备份。

## 验证边界

隔离库测试覆盖无损往返、重复去重、固定上界分页、打开期间并发更新、历史回放及崩溃恢复。性能测量与副本体积只代表被测数据，不等同于界面响应时间或模型生成速度；没有启动浏览器验证。
