# 会员额度展示（本地二次开发）

基于上游 `28ccc6745ec82139c684c3642637e93e00d800f2`，本地版本 `0.2.1-rc.4.1+quota.1`。

入口：插件 → ACP 适配器 → Google Antigravity 卡片 → 刷新额度。

显示订阅类型、模型组的五小时／周剩余额度、重置时间和本次读取时间。会话 token 用量和会员额度分别展示；未提供的值显示未知，失败保留上次结果与读取时间。只读取当前官方 CLI 账号，不聚合或自动轮换多个账号。

## 数据来源

使用官方 `agy --settings` 的临时状态行设置，通过 `statusLine` 回调接收 `quota` 与 `plan_tier`。只调用交互界面的 `/usage`，不发送模型请求、不修改用户 settings.json、不读取或转发 OAuth 凭据、不直接请求 Google 私有接口。

官方文档：https://antigravity.google/docs/cli/statusline

Python3 标准库 PTY 用于承载临时 CLI 会话；读取后关闭进程组并删除临时文件。仅设备所有者可查询。只返回额度、订阅类型和当前登录邮箱的白名单，排除提示词和凭据。邮箱仅向设备所有者展示。查询合并并限制频率，不后台轮询。支持 macOS／Linux，Windows 显示不支持。

依赖：Python3，已登录的官方 Antigravity CLI（实测 1.5.2），可访问 Google 服务的网络。命令路径沿用该 Agent 的可执行文件配置，环境变量沿用该 Agent 的显式配置。

## 验证边界

已通过构建、发布包结构检查、额度解码测试和真实官方 CLI 读取。实测返回 Google AI Pro、Gemini 五小时和周额度及重置时间。所有数据只代表读取时刻，不保证后端额度变化实时推送。

上游精确目标仍为 Harness 0.2.1-rc.4；当前电脑 0.2.2-rc.1 需要精确版本例外。不得仅修改 engines 声明冒称完整兼容。未启动浏览器进行 UI 验收，也未验证三个账号分别登录的情况。

## 安装与回退

先退出 Harness。在插件管理器选择本地构建的 tgz 包。需要版本例外时，只允许该包版本与当前 Harness 的精确组合。保留原有配置备份。重启后在 Antigravity 卡片点击刷新额度。

回退可重新安装 npm 原版 `@zaimokuza/dsh-acp-adapter@0.2.1-rc.4.1`，不要删除会话数据库或认证数据。

## 模型旁额度仪表（quota.2）

通过公开 `conversation.input.right` 插槽在模型选择器前增加双圈仪表。外圈为 Gemini 五小时额度，内圈为周额度；仅当前所选路由实际配置为 Antigravity 时显示。支持悬停、键盘焦点、点击展开，Escape 与外部点击关闭；浮层通过 portal 避免输入栏裁切，并根据视口限制宽高。

初次挂载查询一次；两分钟内复用结果。展开时数据超过两分钟才重新查询；手动刷新有十五秒冷却，并发请求合并。浮层明确显示读取时间和刷新失败状态，不将缓存数据伪装为实时值。

## 紧凑布局与账号（quota.4）

浮层从 310px 缩窄至 248px，标题与会员类型合并一行；重置时间省略年份和秒。展示与额度同批次读取的官方 CLI 登录邮箱，长邮箱截断并可通过悬停查看完整内容。客户端更新机制与应用文件未修改；插件独立安装在用户 profile。精确版本例外不随 Harness 升级继承，升级后需要重新验证插件兼容性。
