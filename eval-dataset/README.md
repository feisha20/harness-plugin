# KuaiBuddy 评测集提取插件 (@local/eval-dataset)

DeepSeek Harness 插件：在左侧菜单栏增加「评测集」插件，调用 `/kuaibuddy-staff` 接口获取前一天客服对话数据，自动进行清洗、价值评估并提取高价值对话构建基准评测集。

## 功能特性

1. **左侧菜单与全局主面板集成**：
   - 注册于 `sidebar.panellist`（id: `eval-dataset`），带有评测集专属图标与中英文国际化标签。
   - 点击后在主区域打开评测集工作台（`main` 槽位，key: `eval-dataset`）。

2. **KuaiBuddy 客服对话自动抓取**：
   - 自动获取前一日（昨日）全部对话列表及消息明细。
   - 支持自定义日期或一键切换今日/昨日数据。

3. **智能评测集挖掘与价值评分算法**：
   - **去噪过滤**：自动识别并剔除 shell 命令、探针脚本及无意义单字问候。
   - **多维度评分 (0-100)**：综合评估提问复杂度、多轮交互深度、工具调用链及结构化排障结论。
   - **场景分类**：自动归类为「异常排障与诊断」、「配置与操作指导」、「业务概念与规则」、「工具调用评测」等。
   - **同场景去重聚类**：自动归并重复探测任务，保留最高分、最完整答案的代表性用例。

4. **交互式评测用例工作台**：
   - 核心指标卡片：昨日会话总量、提取评测样本数、工具调用排障数、平均价值分。
   - 评测输入与参考答案审查、单条复制、入选依据展示。
   - 完整会话回放（Timeline）：访客提问、客服回复、工具调用入参/结果、模型推理（CoT）全链路可视。

5. **多格式导出**：
   - 支持勾选批量导出为标准 **JSON**、**JSONL** 或 **Alpaca** 问答评测集格式。
   - 注册 DSH Tool `kuaibuddy_eval_dataset`，支持 AI Agent 在对话中直接调用提取与查询评测集。
