# DeepSeek Harness 个人工作台插件 (`@mywork/dsh-workbench`)

原生集成至 **DeepSeek Harness (DSH)** 左侧主导航栏的个人工作台插件，具备多通道会话采集、事项看板管理、工作日报增量整理、周报/月报自动归档等全流程功能。

---

## 🌟 核心功能

### 1. 🔌 多通道会话采集源 (Data Sources)
- **DeepSeek Harness 本机会话**：只读扫描 `~/.dsh/sessions` 下的 `session.v4.jsonl.zstd` 和旧版 `session.jsonl.zstd`，支持自定义会话目录。排除空会话、子代理、种子会话及环境/技能注入，仅统计有效用户会话；按会话与北京时间日期生成一句话中文概要，保留真实项目、时间和原话证据，不自动标记工作完成。正文未变时复用概要，模型失败保留已有记录并显示错误。旧版误指向 Antigravity brain 的默认路径会自动迁移，并移除两条内置 DSH 演示事项。
  - Harness 会话解压依赖 `zstd` 命令（macOS 可运行 `brew install zstd`）。自动查找 PATH 与 Homebrew 默认位置，完整读取多帧追加日志；缺少工具或日志损坏时明确报错。
- **Claude Code 会话**：监听并解析本机 Claude Code 日志（`~/.claude`）。
- **Codex 桌面端 / CLI 会话**：只读扫描 Codex 用户目录下的 `sessions` 和 `archived_sessions` 中的 JSONL 日志；默认 `~/.codex`，支持 `CODEX_HOME` 或采集源自定义路径。排除子代理及环境注入消息，按会话和北京时间日期合并，复用模型生成一句话概要，保留真实项目、时间和原话证据。首次同步会整理历史会话，后续正文未变化时复用概要缓存；模型不可用时明确报错并保留原记录。
- **Gemini CLI 会话**：接入 Gemini CLI 历史会话快照（`~/.gemini`）。
- **禅道 Zentao**：支持配置禅道系统地址、账号与 API 凭据，自动同步指派给本人的待办与 Bug 缺陷。
- **采集诊断与状态**：各渠道具备独立的可用性探测、就绪指示、会话统计与一键增量同步能力。打开工作日志页时，若从未同步或距上次同步超过 30 分钟，会自动补一次采集；手动同步按钮始终可用。

### 2. 📋 事项待办看板 (Tasks Kanban)
- **三态流转**：待办（Pending）、进行中（In Progress）、已完成（Completed）。
- **多维度筛选**：支持关键词搜索、按来源渠道过滤、按执行状态快速切换。
- **事项详情与元数据**：优先级（高/中/低）、置顶（Pin）、截止时间、归属工程项目路径。
- **采信证据溯源**：AI 自动抽取的事项保留原始会话消息、时间戳与原话引用（Quote）。
- **手工待办**：支持随时随地快捷新增日常研发待办。

### 3. 📅 工作日报 (Daily Report)
- **自动归集算法**：智能拉取指定日期内完成的事项与进行中的主线任务，按项目自动分组归类。
- **必填章节**：日报固定包含「今日产生的商业价值（业绩、提效、合理降本等）」与「明日计划（事项、商业价值）」，没有对应记录时保留“待补充”提示。
- **AI 自动归纳**：打开任意日期的日报时，若以上两个章节仍是占位内容，会依据当天工作记录自动归纳并写回，标注“请核对后提交”；归纳结果随日报缓存，不重复调用模型。
- **快速日期定位**：提供今日、昨日、前天快捷跳转及日历日期选择器。
- **双模查看与编辑**：结构化事项卡片与 Markdown 文本预览，支持随时手工微调。
- **一键复制**：提供“复制标准日报”快捷操作，一键生成符合企微、钉钉、Slack 规范的工作简报。
- **历史归档**：修改与保存自动持久化存储至本地仓库。

### 4. 📊 周报与月报 (Weekly & Monthly Reports)
- **智能周期边界计算**：
  - **周报**：按 ISO 标准周（周一至周日）聚合当周完成事项与推进中任务。
  - **月报**：按自然月度统计里程碑产出与阶段性交付。
- **标准结构**：
  - **周报**：按六个核心维度组织：
    1. **本周完成的工作**（按工作方向分组汇总）
    2. **本周产出了哪些商业价值（带来的业绩、提效、合理降本等）**
    3. **下周工作计划**
    4. **针对不足，你将采取的措施是什么？**
    5. **重做一遍应该怎么做？会带来哪些变化？产生哪些商业价值？**
    6. **本周下来团队存在最大的问题是什么？（至少写一项）**
  - **月报**：按自然月度统计重点工作与阶段进展、问题与需协调事项、下月工作安排。
- **度量统计卡片**：自动统计周期完成事项总数、攻坚事项数、涉及工程项目数、活跃记录天数。
- **支持手工微调、归档保存与一键复制**。

### 5. 💾 本地持久化 (Zero-Config Persistence)
- 数据持久化存储于用户主目录 `~/.dsh-workbench/workbench-store.json`。
- 基于临时文件与原子重命名写入，保障并发与崩溃安全。
- 零外部数据库依赖，无需启动 Docker 或 PostgreSQL，即装即用。

## 🏗️ 技术架构

本插件遵循 DeepSeek Harness 原生的 **Cordis 插件规范** 与 **Slots 插槽架构**：

```
DeepSeek Harness 宿主
  ├── 左侧导航栏: @deepseek-ai/dsh-client-ui-sidebar
  │     └── 插槽 'sidebar.panellist' -> 注册 WorkbenchIcon (id: 'workbench', order: 15)
  ├── 中央工作区: @deepseek-ai/dsh-client-ui-layout
  │     └── 插槽 'main' -> 注册 WorkbenchApp (key: 'workbench')
  └── 宿主 HTTP 服务: @deepseek-ai/dsh-host-webserver
        └── 注册 '/api/workbench/*' 具名前缀路由 -> 驱动 Store、Collector 与 ReportEngine
```

## 模型设置

在工作日志顶部打开「模型设置」，选择主模型和可选的备用模型后保存。该设置用于新生成的会话概要和日报、周报、月报的「AI 重新整理」。历史概要仍按会话正文复用缓存。 日报、周报和月报的整理请求仅发送工作概要、项目、日期和报告模板。 报告整理的输出预算由所选模型的适配器决定。

模型列表来自 DSH 已启用的提供方。选择「使用 DSH 默认路由」时沿用旧版规则。若 DSH 默认模型来自 ACP，工作日志自动选用普通模型。要使用 Antigravity，请同时安装本仓库的 ACP 适配器 `0.2.1-rc.4.1+quota.4.2` 或更新版本，并在工作日志中明确选择 Antigravity 提供方下的具体模型。Antigravity 请求使用独立的短会话，会将待整理资料发送给所选服务。

主模型调用失败、返回空白或未通过输出检查时尝试备用模型。两者都失败时保留原报告或原有概要，并显示调用错误。

新整理的日报、周报和月报会在标题右侧显示实际使用的模型，切换时标明「备用模型」。历史报告缺少模型记录时显示「整理模型未记录」。 点击「AI 重新整理」时，工作项依次沿金色旋涡弯曲卷入中央，模型返回后按新顺序展开。开启系统的减弱动态效果设置时仅显示整理状态。

## 🛠️ 构建与打包

进入插件目录：

```bash
cd dsh-workbench

# 1. 编译 Host 端 TypeScript 与声明文件
npm run build:host

# 2. 通过 tsdown 打包客户端 Bundle (含 DSH __ModuleLoader__ 包裹层)
npm run build:client

# 3. 完整构建并打包为发布安装包 (.tgz)
npm run pack
```

打包产物位于 `dist/mywork-dsh-workbench-0.1.30.tgz`。

## 🚀 安装至 DeepSeek Harness

### 方式一：通过 Harness 界面安装（推荐）
1. 打开 DeepSeek Harness 桌面端 / Web 端。
2. 点击左侧主菜单的 **插件**（Plugins）图标。
3. 选择 **从本地文件安装**（Install from file...），选中 `dist/mywork-dsh-workbench-0.1.30.tgz`。
4. 重启或刷新页面，左侧主菜单将出现 **工作日志** 入口。

### 方式二：通过 DSH 命令行添加
```bash
dsh plugin add ./dist/mywork-dsh-workbench-0.1.30.tgz
```
